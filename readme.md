# C4

Пример использования C4.

**На GitHub (вкладка репозитория):** вверху по умолчанию показывается этот `README.md` — отдельно настраивать не нужно.

**На GitHub Pages** главная — это не README, а статический `index.html` из каталога `site/`: в workflow он копируется в корень публикуемого сайта, а вывод likec4 — в подкаталог `viewer/`. Сначала пользователь видит лендинг, по ссылке «Открыть превью likec4» — собранные диаграммы.

- Сайт (после деплоя): [https://pankovan.github.io/C4/](https://pankovan.github.io/C4/) — лендинг, [https://pankovan.github.io/C4/viewer/](https://pankovan.github.io/C4/viewer/) — likec4.

**Локально** после `npx likec4 build` открой [dist/index.html](dist/index.html).
